# CMF directory

The **Content Messaging Framework (CMF) v3.0** is required for any Ālo product site **content** revamp — not just visual reskinning.

| File | Purpose |
|------|---------|
| [`CMF-v3.md`](CMF-v3.md) | Canonical framework — 14 components, three acts, compression rules, common errors |
| [`WORKSHEET-TEMPLATE.md`](WORKSHEET-TEMPLATE.md) | Blank worksheet — fill per product before writing homepage copy |
| [`examples/silver-bullet-worksheet.md`](examples/silver-bullet-worksheet.md) | Completed reference (Silver Bullet homepage, 2026-06) |

## When to use

- New product marketing site  
- Homepage narrative overhaul (like Silver Bullet 2026 revamp)  
- Re-aligning help-center story with homepage CMF map  

## Pair with

- [`DESIGN.md`](../DESIGN.md) + [`kit/`](../kit/) — look-and-feel  
- [`skills/alo-site-revamp/`](../skills/alo-site-revamp/SKILL.md) — agent workflow for full revamp  

**Rule:** Never ship a content revamp without a completed worksheet and explicit CMF section map in HTML comments (`<!-- CMF C2: ... -->`).
